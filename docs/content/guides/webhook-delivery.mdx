### What we'll build

- An `endpoint` workflow per customer endpoint that holds an ordered outbox of events to deliver.
- Signed payloads, so customers can check that each webhook came from you.
- Retries with backoff and a record of every attempt, with its status code and timing.
- A rule that disables an endpoint after repeated failures and keeps its events until it is turned back on.
- Actions your customer portal calls to show the delivery log and re-enable an endpoint.

### Similar tools

This is the same job as Svix, Hookdeck Outpost, Convoy, or Inngest. On Rivet each customer endpoint is its own Actor, so one slow or broken endpoint backs up only its own outbox, and the outbox, attempts, and disabled flag live in that Actor's storage instead of a shared table.
