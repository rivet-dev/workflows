### What we'll build

- An `aiJob` workflow per job that runs extract, enrich, summarize, and publish as separate recorded steps.
- LLM steps that retry with backoff when the provider returns a rate-limit or server error.
- Tool steps that call your own APIs to add data between LLM calls.
- A `/jobs` route that starts a job and returns its id right away.
- Progress events that let your app show which step a job is on.

### Similar tools

This is the same job as Vercel Workflow DevKit, Inngest, Trigger.dev, Temporal, or Cloudflare Workflows. On Rivet the workflow runs inside an Actor, so each job also has its own state and SQLite database and can push progress to connected clients without a separate pub/sub service.
